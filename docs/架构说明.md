# 架构说明

## 总体结构

```
hbbxl/
├── hbbxl-common/            公共模块(与魄力学习同构)
│   ├── hbbxl-common-core       R包装/异常/鉴权注解/BaseEntity/操作日志
│   ├── hbbxl-common-security   JWT工具/BCrypt/PermitAll自动配置/RSA
│   ├── hbbxl-common-mybatis    MyBatis-Plus配置
│   └── hbbxl-common-redis      Redis配置
├── hbbxl-gateway            网关(8800): 路由/X-User-Id头注入/角色透传/加密信封
├── hbbxl-auth               认证(8801): 登录发token(Redis 24h)/登出拉黑
├── hbbxl-user               用户(8802): 账号/学生信息/角色
├── hbbxl-college            院校专业库(8803)     ← 咕咕数据3075所院校数据入库目标
├── hbbxl-score              分数位次(8804)
├── hbbxl-aspiration         志愿填报(8805)
└── hbbxl-recommend          智能推荐(8806)
```

## 接口规范(与魄力学习完全一致)

- 统一包装 `R<T>`: `{code, message, data}`,code=0 成功
- 统一分页:MyBatis-Plus IPage,入参 page/size,前端按窗口高度自适应页大小
- 鉴权:网关校验 JWT → 下游服务收 `X-User-Id` / `X-User-Role` 头;服务内用 `@RequireRole("admin")` 控角色
- 角色:admin / teacher(后续按需扩展家长角色)
- 多环境:Nacos 命名空间隔离,本地 dev=hbbxl-test,生产 hbbxl
- 常见陷阱(与魄力学习相同,直接沿用结论):改 bootstrap.yml 必须重建 jar;空号判断按"内容非空"而非"非null"
