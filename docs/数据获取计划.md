## 四、方法论（踩坑沉淀）

1. **优先 xlsx/pdf 附件**（file.hebeea.edu.cn 这类文件服务器直链），网页表格次之，扫描图 OCR 兜底（rapidocr，按列坐标解析，只信累计列）
2. 考试院文章 URL 形如 `/c/YYYY-MM-DD/id.html`，列表页翻页 `index_N.html`；改版后历史文章不在新栏目里（河北 2024 教训）
3. 导入脚本模式：parse_file 自动识别年份/批次/科类（标题行正则）→ 按维度 DELETE 幂等重跑 → executemany 批量插入
4. 院校名归一：去 `[性质]` 与 `(城市/校区/项目)` 括号后缀后与 college 表匹配（河北实测 98%）；两地办学（地大/石大/华电等）需特判
5. 投档最低分空白 = 该专业无投档记录，跳过不导（score_line 以 min_mark 为核心维度）
6. 每完成一省：数据落库 + 本文档勾选 + 开发日志记录
