# 志愿填报模块 功能规格（据用户 2026-10-07 口述+抓包整理）

> 本文档是志愿填报模块的唯一功能依据。参考系统：gexuejy.com（用户抓包其接口定契约）。
> 铁律见 [数据获取计划.md](数据获取计划.md)：高考数据一律取自各省考试院。

## 1. 系统定位

- **砚衡AI云数据升学规划系统**，面向**全国高考生**，核心板块 = **高考志愿填报（3+1+2 模式）**
- 角色：管理员开通账号给**填报师**使用（无自助注册）；账号有效期 1 年（类会员），到期自动停用、违规可手动停用、续费恢复
- 权限：所有有效填报师账号共享学生方案并可进行志愿填报，方案 `user_id` 只记录创建人，不作为数据隔离条件；管理员同样可以操作
- 页面全部 **1:1 复刻**参考系统；业务逻辑一律写 Service 实现类

### 综合查询 · 招生信息（3+1+2）

- 菜单：综合查询 → 招生信息（3+1+2）；页内标题「高校录取数据查询（3+1+2）」
- 筛：考生省份/年份/组别/批次 + 高校省份/城市/名称/包含专业
- 列表：院校代码|名称|省份|城市|招生计划|批次|组别；行可展开看该校专业（名称可点开专业明细，校名点开院校明细）
- 数据：河北 `recruit_major` 按 `uab_id` 聚合；不复刻「追踪溯源」外链

### 综合查询 · 历年省控线查询

- 筛：省份、年份（选省后联动有数据年份）
- 表：省份|年份|批次|文理科/组别|录取分数线
- 数据：`control_line` 本科批/专科批；组别展示为物理组/历史组

### 综合查询 · 一分一档表查询

- 筛：省份 → 年份 → 文理科/组别；一分一档表类型(全部/本科/专科)；查询与导出 Excel
- 表：省份|年份|一分一档表类型|文理科/组别|分数|人数|累计人数
- 数据：`score_ranking`；本科按≥本科批省控线切分，专科为控线以下

### 综合查询 · 综合查询工具

- 参考：格学外链「院校查询」SPA（省/市/名称检索 + 专业查询/专业搜索/职业查询）
- 院校查询：省份→城市联动 + 名称搜索；列表展示校名与内部编码（注明不可用于填报）；点校名开详情抽屉
- 专业查询：教育部 `major` 目录按门类/专业类浏览，点专业看开设院校
- 专业搜索：按专业名在 `college_major` 联想，再看开设院校
- 职业查询：暂无职业库，占位提示
- 数据：`college` / `college_major` / `major`

### 个人信息维护 · 基本资料

- 菜单：个人信息维护 → 基本资料（对齐参考站顶栏「编辑个人信息」；参考站 ComingSoon，本系统落地实现）
- 可改：姓名/昵称/手机/邮箱/性别/签名；登录账号与有效期只读
- 接口：`GET /user/me`、`PUT /user/profile`

### 个人信息维护 · 修改密码

- 参考：格学 `ChangePassword.aspx`（原密码/新密码/确认密码；绿「修改」/红「取消」）
- 改密成功后强制重新登录
- 接口：`PUT /user/password`

## 2. 填报师工作流

```
仪表板 → 填报方案 → 添加学生(姓名/性别/省份/批次/高考分数/位次/选科)

一键迁移、数据采集二维码不做。
       → 点学生姓名 → 学生详情
       → 点志愿名称 → 录取情况报告(已选志愿提档线红黄绿)
       → "志愿填报"按钮 → 进入填报子页面(四个Tab)
       → 添加志愿 → 交单 → 该生"填报"栏显示已交单
       → 前台交单 → 志愿交单(3+1+2)：已交单列表 / 志愿名称→报告 /
         交单人→只读打开填报页 / 退回(撤销交单)
```

## 3. 填报子页面：顶部四个 Tab

| Tab | 语义 | 数据形态 |
|-----|------|---------|
| **智能专业推荐**(默认) | 按学生分数/位次/选科+已存筛选+滑杆(向上/向下分数)算候选专业池 | 行含录取概率、历史等效数据(智能筛选模式下概率=未知) |
| **按高校检索** | 定向查: 高校/专业/城市/**预测最低分不高于**某分 | 系统最多返回 200 条 |
| **首次招生高校** | 新升格/新设专业，**无历史录取数据** | 列结构不同(无概率/排名/等效列): 操作\|高校专业\|科目要求… |
| **查看结果** | 已按专业/按学校添加的志愿总表 | 勾选可**导出 Excel** |

筛选三维度（都挂在志愿方案 AspirationCode 下持久化）：
1. **专业筛选** = 白名单（AddMajors 逐条加 MajorIDs）；筛选池 = 门类→一级学科→专业名检索，最多显示 200 条；专业字典**独立建表维护**（zytb.major，815 条教育部 2024 目录）
2. **院校筛选** = 存**排除数组**（未勾选的省份/院校类型/属性/性质，空数组=全包含）
3. **其它筛选** = 学制/学费区间/关键字包含不包含等

## 4. 推荐引擎三段式（346万+条专业数据 → 必须异步）

参考系统抓包确认的契约（我们同构复刻，通知通道用 WebSocket/SSE 替代其 SignalR）：

1. `RecommendMajors{AspirationCode, UpperParam:向上分数, LowerParam:向下分数}` —— **命令**：后台物化计算，立即返回 `RecordCount`（实测：20/60→173 条；60/60→262 条，滑杆扩池）
2. 计算完成 → **推送通知**
3. `GetRecommendMajors{AspirationCode}` —— **拉取物化结果**：46 字段行集（双重序列化 JSON，注意解两层）

物化结果行（46 字段关键项）：
- **院校维度**: UnvCode/UnvInnerCode/UnvName[性质]/BaikeUnvName/MapUrl/Province/City/UnvRank(高校排名)/UnvNature/UnvType/UnvAttributes/**HasMasterUnit/HasDoctorUnit**(硕博点)/IsNew/**UnvFirstTimeAdmission**(首次招生)
- **专业维度**: **RecruitMajorID=`26冀本理1869-30`**(年+省+批次科类+院校代号-专业代号=志愿单元主键)/MajorCode/MajorName/**MajorPlan(计划)/SchoolLength(学制)/Tuition(学费)**/RecruitPlanExplain/RequiredSubjects(选科)/ElectiveSubjects/MajorCodes(教育部专业代码↔major字典表)
- **预测维度**: PreAvgMark/PreMinMark+Rank/Percentile（智能推荐模式出概率，智能筛选=未知；RecruitProbability=9999.0 为内部哨兵）
- **历史等效 MajorHistorys[]**: 每年一条 Year/MinMark(原始分)/EquivalentMinMark/**MinMarkRank**

**等效分换算算法（核心）**：按一分一段表，往年原始分→该年位次→目标年份(2026)同位次分数。
例：2025 年 511 分 → 位次 142016 → 2026 年一分一段同位次 = 506(等效)。三年数据因此可比，与考生分数比出红黄绿。

**滑杆过滤键（已钉死）**：过滤键 = `PreMinMark`（预测最低分），不是等效分。
- 区间：`[max(考生分−LowerParam, 省控线), 考生分+UpperParam]`
- 证据：源站样本 `GetRecommendMajors.json`（n=262）恰为 490 分、Upper/Lower=60/60 且地板=河北2026物理本科省控线 443 时的 PreMin 集合；等效分可到 589（越出区间）但行仍保留 → 证明非等效分过滤
- 文档旧说「20/60→173」与样本按 PreMin∩[443,510]=176 接近，差额来自选科/院校/其它筛选，非过滤键差异

- Sheet「志愿单」，20 列 A~T，三行表头：

  - 第3行列头：序号|院校代码|院校|专业名称|专业备注|选科要求|计划|学制|学费|排名|等级|2025|2024|2023…

## 7. 范围调整与河北口径（2026-10-08 拍板）

- **志愿填报只做河北省**，其他省份暂缓；不再自行爬取，数据由用户下载提供（`F:\教育考试院\河北省\`）
- 数据源：
  - 2026 招生计划+2021~2025 历年专业分/位次+院校扩展信息：4 个志愿数据 xlsx（本科/专科 × 物理/历史，共约 5.1 万招生专业）
  - 一分一段：`一分一档数据\2021-2026年 河北高考一分一档表.xlsx`（含优惠分；"分数线"sheet 为 2016~2024 控制线）
  - 控制线：2021~2026 汇总于 `docs/sql/tools/data/hebei_control_lines.csv`（2025/2026 为用户提供）
  - 官方投档线：2022~2026 本科批/专科批 × 物理类/历史类已从考试院入库。2021 无官方投档线，该年历史院校/专业代码先空着不补。2022~2025 相对 `score_line` 唯一命中（含专业名去括号）的历史代码已回填约 120689/129548；仍不唯一的约 8859 条显示 `-`
- **志愿数量上限：本科批、专科批普通类均为 96 个**
- 等效分算法（已用参考系统 697 个样本验证）：
  - 百分位 = (1 − 位次 ÷ 当年本科批控制线上累计人数) × 100（源年份 697/697 精确一致）
  - 等效分 = 2026 一分一段中百分位（同口径，分母取 2026 本科线上累计）最接近的分数档（599/697 一致，其余 ±1 分）
- 录取概率：参考系统前端 `CalculateProbability`（aspmng-2.js），参数 UpperBound=30/LowerBound=20/MinMarkProbability=40/AvgMarkProbability=60。预测最低分：有官方投档用官方最低分，否则用历年等效最低分中位数（查询时计算，不落库）；没有历年等效分则为空。预测平均分规则仍不定

## 8. 填报子页面实现（2026-10-08，复刻 AspMng.aspx）

- 入口：填报方案列表「填报志愿」→ 新窗口打开 `/fill/{aspirationCode}`（独立全屏页，不套后台布局）；`/fill/{code}?split=1` 为分屏显示（只读已选志愿，主窗口任何增删/排序后经 BroadcastChannel 通知自动刷新）
- 顶部：学生名（点击展开左侧学生信息栏）【志愿填报】省份，批次；分数，排名；组别；选科 + 右上「刷新数据」
- 智能专业推荐：专业筛选 / 院校筛选 / 其它筛选 + 向上/向下分数滑杆（10~60）+ 智能筛选（已有推荐时先确认"操作存在风险"）+ 一键填报（可选数 0~上限+20−已选，默认补满上限）；列表按 100 条分页滚动加载
- 按高校检索：高校/专业/城市/预测最低分不高于，最多 200 条，按录取概率升序、预测最低分降序
- 首次招生高校：高校/专业/城市，最多 300 条，独立列结构
- 查看结果：清除高亮 / 全部删除 / 新排序（卡片拖拽）/ 老排序（表格拖拽）/ 浏览报告 / **导出勾选**（行内复选框，按志愿顺序导出）/ 分屏显示 / 高校+专业过滤（序号保持原始序号）
- 排序弹窗：移到第 N 号之前 / 移到末尾 / 系统自动排序（1 按录取概率 2 按预测最低分 3 按上年录取最低分）/ 保存
- 志愿报告：考生信息、成绩、全省分数位次定位图、同分人数分析图（ECharts）、志愿单预览、说明/结语/附录（品牌为砚衡，不含参考系统的广告图和二维码）；底部「下载Excel志愿单」导出全部、「打印」在新窗口打印（图表转图片）
- 一键填报取推荐列表中未选的前 N 条；推荐列表按 **预测最低分从高到低**（与源站 `GetRecommendMajors` 排序一致，高预测分=更难进=冲在前）。数量规则 `上限+20−已选` 与源站前端一致。源站 `OneClickGeneration` 服务端闭源，现有抓包/前端无冲稳保配比证据；在未捕获「同一池选中集合」前，按推荐序取前 N 为当前对齐实现
- 预测分：有当年官方投档时 `PreMinMark` 用官方最低分（有投档线的样本 258/262 与源站精确一致）。没有官方投档、但有历年等效最低分时，接口现算中位数再返回，不写回 `pre_min_mark`。完全没有历年等效分的继续为空。`PreAvgMark` 源站亦极少返回（推荐样本仅 4/262，已选/首招样本为 0），暂不强行补全
