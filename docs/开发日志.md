### 服务器部署配置要求（生产）

**运行形态**：Docker Compose 启 7 个后端（host 网络，端口 8800–8806）+ 前端 nginx 镜像（默认 80，`/api` 反代本机 8800）。Jenkins 只构建镜像，部署见 `docker/docker-compose.yml` + `docker/.env`。

**中间件（可与魄力学习同机复用，命名空间/库隔离）**

| 组件 | 用途 | 说明 |
|---|---|---|
| MySQL 8.x | 业务库 `zytb` | utf8mb4；表脚本 `docs/sql/rebuild/`；建议独立盘、备份 |
| Redis | token / 验证码 | 前缀 `hbbxl:token:`、`hbbxl:captcha:` |
| Nacos 2.x | 注册与配置 | 生产命名空间 `hbbxl`（本地测试为 `hbbxl-test`） |
| MinIO（可选） | 院校 logo 等对象存储 | 有 logo 上传/迁移时需要 |

**应用容器内存上限（compose 已写）**：gateway 512MB；auth/user/college/score/aspiration/recommend 各 352MB → 后端合计约 **2.6GB**。另加 nginx 前端约数十 MB。

**推荐机器规格**

| 场景 | CPU | 内存 | 磁盘 | 备注 |
|---|---|---|---|---|
| 最小可跑（中间件已在别机） | 4 核 | **8GB** | 40GB SSD | 仅跑 7 服务 + 前端；余量给 OS/峰值 |
| 一体机（含本机 MySQL+Redis+Nacos） | 4～8 核 | **16GB** | 100GB+ SSD | MySQL 建议单独留 4GB+ 内存 |
| 填报高峰/并发更高 | 8 核 | 16～32GB | 200GB SSD | 可上调各服务 `mem_limit` 与 Hikari 连接池 |

**开放端口**：对外通常只开 **80/443**（前端）；后端 8800–8806 建议仅本机或内网。Nacos 8848、MySQL 3306、Redis 6379 勿对公网裸开。

**软件环境**：Linux amd64；Docker + Compose；构建机需 JDK 17 / Maven 3.9（或沿用 Jenkins 内 `maven:3.9-eclipse-temurin-17` 镜像）。前端构建 Node 20。

**配置注意**：生产 `SPRING_PROFILES_ACTIVE=prod` → Nacos 命名空间 `hbbxl`；数据源/Redis 密码以 Nacos 或各服务 prod 配置为准（本地开发默认 MySQL `127.0.0.1/zytb`，Nacos/Redis 现为远程）。改数据源后必须重新打包镜像，旧 jar 仍连旧库。

**操作手册**：虚拟机逐步部署见 [部署说明.md](部署说明.md)（中间件 → 导库 → 构建镜像 → compose 启后端 → 单独启前端 web）。
